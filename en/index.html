Grounded

Minecraft as it could actually exist.

A Fabric mod for Minecraft 26.3. There is no magic, no mysticism and no teleporting: every fantastical mechanic is re-explained as physics, chemistry or industry. Almost everything you know is still where it was - it just became honest.

The idea

One test: could this exist?

If yes, it stays. If not, it is explained anew or it goes. The mod does not add a new world - it rethinks the old one: most items and mobs behave as before, but have new names, looks and voices. The world stands on three pillars.

🧍People

Blackroad gangs on the Overworld's roads and the Cinder Company, mining sulfur and ore in the volcano. There are no undead: the night is dangerous because of those who live by robbery.

🤖Machines

The legacy of a collapsed industrial project: high-altitude stations, automatons, drones. They are not evil but unfinished - running a protocol set by people who are gone.

🐾Animals

Real animals stay animals. Bones now come from animals, while machines drop scrap metal.

Download and install

Installation

You need Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API and Java 25. The easiest way is the ready MultiMC instance: it holds everything but the game itself, which the launcher downloads on its own.

MultiMC and Prism Launcher

  1. Download Grounded-MultiMC-1.2.0.zip.
  2. In the launcher: Add Instance → Import from zip → pick the file → OK.
  3. In the instance settings (Edit Instance → Settings → Java) choose Java 25. If you have none, get Adoptium Temurin 25.
  4. Launch. The first time, the launcher downloads Minecraft and Fabric.

The descriptions of Minecraft and Fabric travel inside the instance, so MultiMC's own server is not needed to install it. The version list marks them as customized - that is intended.

The instance already carries the Java arguments Mojang's launcher starts the game with: MultiMC does not pass them itself, and without them Minecraft 26.3 can crash silently. For an instance set up by hand or downloaded before 1.1.1 - Edit Instance → Settings → Java → JVM arguments: -XX:StackShadowPages=32 --enable-native-access=ALL-UNNAMED --add-exports java.base/jdk.internal.misc=ALL-UNNAMED

The official launcher

  1. Install Fabric Loader for 26.3 with the Fabric installer.
  2. Download grounded-1.2.0.jar and Fabric API for 26.3.
  3. Put both files into the .minecraft/mods folder.
  4. Start the Fabric profile.

On a server the mod is needed by the server and by every player: the same two files go into the server's mods folder.

Language

The mod is written in Russian first and fully supports English. The MultiMC instance starts in Russian; switch under Options → Language.

A new world

Better start a new one: the Summits' terrain is made at generation, and in an old world the places already explored stay as they were.

Updating

Delete the old grounded-…jar from mods and put the new one there: the game will not start with both. Worlds are kept. What's new and every version are on the releases page.

Travel

Pads instead of portals

There is no teleporting anywhere. An obsidian frame will not light, the Summits' portal will not open, there is no chorus fruit, and the Grappling Hook (ender_pearl) is a rope with a hook: it does not move you, it pulls you. To the volcano and the Summits you fly: a craft comes to pick you up from a pad.

Calling a craft

Build a 5×5 pad and stand on its centre. "They are coming for you" - stay for 3 seconds and the craft takes you. Step off before that and the flight is called off. The centre decides where to: a Control Block - the volcano, a Coordinate Receiver - the Summits.

Arrival

The first flight finds solid ground, and a moment later the same pad rises under you. It is built once: take it apart and you fix it yourself - there is no block farm. Later flights land on it. In the volcano, lava next to the pad sets into basalt.

Going back

Step off the arrival pad and onto its centre again - the craft brings you back to the pad you left from.

The way to the Summits

A Tracking Probe flies towards a stronghold. Every chest in its library holds a Coordinate Sensor - the part the Coordinate Receiver for the pad is built from.

Evacuation from the Summits

There is no exit portal. When the Summit Guard is put out of action, the podium's floor becomes an evacuation pad. The first time you get the flight recorder's log and the credits, then you are home; after that it is an ordinary flight back.

To the outer islands

There are no gateways. Instead, transfer pads rise on the main island after the Guard. Stand on the frame in the middle and a craft takes you to the outer islands, where the same pad appears. There and back as often as you like.

What is crafted differently

Recipes that needed materials with no honest explanation now use industrial ones: iron, copper, gunpowder, wiring. The vanilla recipes of these items are replaced, not added alongside. The grey label is the item's old id.

Robots

Built from blocks - the head is always a control block

These machines are built from iron, copper and snow, so they are robots - in place of the iron_golem and its kin. Each one's head is a Control Block; a pumpkin lantern will not do.

Systems

The mechanics stay, the explanations are new

Mods

Gear is fitted with mods. Mod is the consumable, a Mod Cartridge the medium, a Written Cartridge a finished mod, a Cartridge Rack powers the Modification Bench. Experience is data: Data Fragments, the Data Cell. The Service Bench and the Reset Bench are benches.

Wiring

Redstone is Wiring: boards and wires of the collapsed project, dug out of the rock. A single wire lies as a pad. Signal Torch, Electric Lamp.

Compounds

A Compound (potion) is made on a Chemistry Station: base, thrown and aerosol kinds. The effects are chemistry - invisibility, for one, became camouflage.

Stations

A Power Station is built around a Power Core and powers everyone's gear nearby. The Underwater Station does the same under water; its core is the Sea Core.

Put out of action

The player never dies but is put out of action - and returns to the game at the spawn point. Animals and the world's people die as before: they do not come back.

Assembly capsules

The *_spawn_egg items are capsules: they assemble a machine or release a creature. Each carries a portrait of what is inside.

There are no religious symbols, superstitions or ghosts in the game - neither in texts nor in textures. Even the crosshair became a ring.

The world

The Volcano and the Summits

The Volcano

Formerly the_nether - an active volcano where the Cinder Company mines sulfur and ore. Here is Volcanic Rock, volcanic wastes and fortresses, Refractory Ingot. The volcano's machines work here - burner drones, balloon drones, walking loaders. The only way in is a flight.

The Summits

Formerly the_end - islands on thin stems over a sea of clouds: nothing hangs in the air. Day and night under a dark high-altitude sky, and the first arrival is in the morning. The islands are Limestone, with empty high-altitude stations of prefab panels on them, airships alongside, and a Pack Wing on board. The main island is guarded by the Summit Guard, powered by Charging Emitters. The ending is the flight recorder's log instead of a poem.
