# Grounded

**Minecraft, который мог бы существовать** — мод для Minecraft 26.3 на Fabric: ни магии, ни мистики, ни
телепортов; каждая механика объяснена как физика, химия или промышленность.

**Minecraft as it could actually exist** — a Fabric mod for Minecraft 26.3: no magic, no mysticism, no
teleporting; every mechanic re-explained as physics, chemistry or industry.

- Сайт / Site: https://baudi2.github.io/grounded/ ([English](https://baudi2.github.io/grounded/en/))
- Скачать / Download: [releases](https://github.com/Baudi2/grounded/releases)
